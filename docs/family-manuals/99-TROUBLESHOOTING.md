## The Universal Fix (Try This First)

### The "Pull Down Refresh" (Solves 50% of problems)

1. Put your finger on the top of the screen
2. Pull down (like pulling down a window shade)
3. Let go
4. Wait for the spinning wheel to stop
5. See if problem is fixed

**Why this works:** Your app stores data locally, then syncs. Sometimes the screen shows old data. Refresh grabs the latest.

---

## The Universal Fix #2 (Try This Second)

### The "Close and Reopen" (Solves 30% of problems)

**On iPhone:**
1. Swipe up from bottom (or double-tap home button)
2. Find your app in the list
3. Swipe it up to close
4. Tap the app icon to reopen

**On Android:**
1. Tap the square button (bottom right)
2. Find your app
3. Swipe it away
4. Tap the app icon to reopen

**Why this works:** Apps sometimes get confused. Closing clears their brain. Reopening gives a fresh start.

## Problem: "The screen is blank/white/empty"

### Quick Fix:
1. Wait 10 seconds (count slowly)
2. Pull down to refresh
3. Check your internet (open a web browser, see if it loads)
4. If no internet: This is normal. The app works offline. Your data will appear when internet returns.

### If Still Blank:
1. Close and reopen app
2. Check if you're in "Home" or "Business" mode (toggle at top)
3. Try the other mode

### Call Will If:
- Blank for more than 2 minutes after refresh
- Blank after reopening
- Error message you don't understand

## Problem: "My data disappeared"

### Don't Panic. It's There.

**Most likely:** You're looking at the wrong mode or filter.

### Check These:

1. **Home vs Business Toggle** (top of screen)
   - Tap it. Switch modes. See if data appears.
   
2. **Date Filter** (if your app has dates)
   - Check if you're looking at "Today" when you want "This Week"
   - Tap date buttons to change

3. **Zone Filter** (Warehouse AJ)
   - Check if you're viewing "Zone 1" when item is in "Zone 5"
   - Tap "All Zones" to see everything

4. **Search Box** (if you were searching)
   - Clear the search (X button or delete text)
   - All items appear when search is empty

### If Still Missing:

**Mama (Culinary):**
- Check "Home" vs "Business" pantry (toggle at top)
- Recipe in one mode won't show in the other

**AJ (Warehouse):**
- Check zone filter
- Check if item is marked "Sold" (moves to Zone 9)

**Carrie (Maid Manager):**
- Check date — looking at wrong day?
- Check if job is marked "Complete" (moves to history)

**Christyn (Cheomatica):**
- Check client list — maybe in wrong view

## Problem: "Voice commands don't work"

### Check 1: Internet Connection
- Voice needs internet to understand you
- Check: Can you open a website in your browser?
- If no internet: Use buttons instead until signal returns

### Check 2: Microphone Permission
- Your phone might have blocked the app from using microphone
- **iPhone:** Settings → Privacy → Microphone → [Your App] → ON
- **Android:** Settings → Apps → [Your App] → Permissions → Microphone → Allow

### Check 3: Speaking Clearly
- Wait for the green light before speaking
- Speak slower than normal talking
- Use simple words: "Add eggs" not "I would like to add some eggs please"
- Try again 2-3 times before giving up

### Check 4: The App Heard Wrong
- Voice recognition isn't perfect
- If it understood "six" as "sex," that's an error — try again or use buttons
- Add to voice training: Settings → Voice → Train (if available)

### When to Use Buttons Instead:
- In loud environments
- When internet is spotty
- When voice keeps misunderstanding
- When your hands work fine (buttons are fast too!)

## Problem: "I can't log in / It wants a password"

**YOU DON'T LOG IN. YOU DON'T HAVE A PASSWORD.**

These apps don't use passwords on your device. They use something called "SBT" (Soulbound Token) that happens automatically.

### If You See a Password Screen:
1. You're on the wrong website
2. Check the URL — should be `https://[app-name].pages.dev`
3. If the URL is wrong, close it
4. Open your bookmarked link instead

### If You're Asked to "Sign In":
1. Don't
2. Text Will immediately
3. Something is misconfigured

### Do This:
1. Screenshot the error (usually: hold power + volume down)
2. Text screenshot to Will
3. Say what you were trying to do
4. Will translates "technobabble" to English

### Common Error Translations:

| Error Says | Actually Means | Fix |
|------------|----------------|-----|
| "Syntax error" | App confused by data | Refresh |
| "Network timeout" | Internet too slow | Check connection |
| "Duplicate key" | You already added this | Edit existing instead |
| "Null pointer" | App looking for something not there | Refresh and retry |
| "Sync failed" | Couldn't reach the mesh | Keep working, sync later |

## 🛑 The Nuclear Option (ABSOLUTE LAST RESORT)

### ⛔ STOP — Read This First

**🛑 ONLY do this if Will explicitly says to, or if the app is completely broken and nothing else works. 🛑**

**You will NOT lose data** — it's synced to the mesh. But you'll need help getting back in (text Will).

### Clear App Data and Start Fresh

**iPhone:**
1. Settings → General → iPhone Storage
2. Find your app
3. Tap "Offload App" (keeps data) or "Delete App" (removes everything)
4. Reinstall from App Store or bookmark

**Android:**
1. Settings → Apps
2. Find your app
3. Storage → Clear Cache (try this first)
4. If still broken: Storage → Clear Data
5. Reopen app
