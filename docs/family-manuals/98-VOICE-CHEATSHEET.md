## How to Use Voice (Every App)

1. **Tap the 🎤 button** (bottom of screen)
2. **Wait for GREEN light** (or beep)
3. **Speak clearly** (slower than normal talking)
4. **Wait for response**
5. **If wrong:** Tap 🎤 again, speak slower

**Voice needs internet.** If no signal, use buttons instead.

## 🐛 BUG REPORTER (All Apps)

**Tap the ladybug 🐛 button when something's wrong**

### What to Say:
```
"I was trying to add six eggs to the pantry"
"I expected it to add the eggs"
"But instead it said 'syntax error'"
"Yes" (if it asks if you see an error on screen)
"Done"
```

### That's it. Will gets:
- What you described
- Screenshot
- Technical details
- Full context

**No need to figure out what's wrong. Just describe what you see.**

## 🔊 Voice Tips (All Apps)

### Speak Like This:
- **Slower** than normal talking
- **Clear** — don't mumble
- **Simple** — short sentences work best
- **Keywords first** — "Add" or "Start" or "Show"

### If It Doesn't Work:
1. Try once more, slower
2. Try once more, louder
3. Use buttons instead
4. Text Will

### Works Best When:
- Quiet room
- Phone close to mouth (6 inches)
- Good internet
- You're not rushing

### Numbers:
- Say digits: "six N" not "six en"
- Say "twenty" not "2-0"
- Say "one-two-three" not "one hundred twenty-three"

## 🚫 When Voice Won't Work

**Use buttons instead when:**
- ❌ Loud environment (salon, warehouse, busy kitchen)
- ❌ No internet signal
- ❌ Voice keeps misunderstanding
- ❌ You're frustrated with voice

**Buttons work great. Voice is convenience, not requirement.**

---

## 🔧 Quick Fixes

### Voice Button Grayed Out?
- Check internet (open a website)
- Check microphone permission in phone settings
- Restart app

### Voice Hears Wrong Thing?
- Speak slower
- Use different words
- Or use buttons

### Voice Says "I didn't understand"?
- Try simpler command
- Check cheat sheet for exact phrasing
- Some words work better than others
