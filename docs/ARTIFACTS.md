## Health Metrics Gauges (Feeler Gauge Set)

As part of our observability improvements, we've implemented a set of health metrics inspired by motor/generator repair diagnostics:

### Service Multimeter (Resource Metrics)
- `cpu_pct`: CPU usage percentage
- `rss_mb`: Resident Set Size in MB  
- `disk_iops`: Disk input/output operations per second (placeholder)

### Latency/Jitter Gauge
- `latency_p99_ms`: 99th percentile latency in milliseconds
- `latency_jitter_ms`: Jitter (p99 - p50) latency in milliseconds

These metrics are included in health endpoints where available:
- Dynamic endpoints: p31ca.org/health, Worker /health endpoints
- Static health.json files: Updated to include build-time placeholders

Golden Canary Service: https://p31ca.org/canary.health.json
- Returns known-good vector to verify platform health
