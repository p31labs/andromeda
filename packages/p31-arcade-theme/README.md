# P31 Arcade Theme

Canonical arcade styling for P31 games — derived from `p31-universal-canon.json`.

## Usage

```css
@import '@p31/arcade-theme/arcade-theme.css';
```

## Design Principles

1. **Gray Rock Compliance:** No self-starting animations. Use `?alive=1` to bypass for demos.
2. **Canonical Colors:** All colors from `p31-universal-canon.json` palette.
3. **Atkinson Hyperlegible:** All text uses canonical font stack.
4. **Reduced Motion:** Respects `prefers-reduced-motion`.

## Tokens

See `p31-universal-canon.json` for full token reference.
