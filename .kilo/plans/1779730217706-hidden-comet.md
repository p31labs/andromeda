## Phase 2 Sprint 5.1: Visual Restoration (Completed) ✅

### Root Cause
`@astrojs/tailwind` configured with `applyBaseStyles: false` requires an explicit CSS file importing Tailwind layers. Without it, Vite produced zero CSS chunks — all Tailwind classes (`fixed`, `z-10`, `grid`, `flex`, etc.) were silently dropped, collapsing the layout.

### Fix
- Created `src/styles/global.css` with `@tailwind base/components/utilities`
- Imported from `PHOSRoot.tsx` (JS side-effect import ensures Vite processes it)
- Reinforced z-index: wrapped `PHOSShell` + `PHOSGuide` in `<div className="relative z-10">`
