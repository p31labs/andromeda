# UI/UX Pivot: Classic vs Quantum Spectrum Implementation Plan

## Overview
This plan implements the "Classic to Quantum" UI spectrum pivot for the P31 family onboarding experience. The goal is to create a seamless transition from the warm, tactile "Classic" (1-Spoon/Survival) mode to the technical "Quantum" (6-Spoon) view, mapping to the WYE→DELTA narrative.

## Current State Analysis
- `FacetSwitchboard.tsx` already implements the 3-facet system with framer-motion transitions
- `DeltaRunwayIgnition.tsx` already has the 1-Spoon button design with warm sunset gradients
- `ClassicFacet.tsx`, `BridgeFacet.tsx`, `QuantumFacet.tsx` exist with distinct styling
- Design tokens partially aligned but need refinement per the spec
